      Behind the counter

      Metabase runs as a managed add-on on Clever Cloud: a Java application with Metabase pre-loaded, and its own PostgreSQL for its users, questions and dashboards. The platform keeps it on the latest Community Edition. It reads the bakery database with the add-on credentials: nothing is copied, nothing is exported.

      Provisioning log

      The companion app sets Metabase up through its REST API at every boot: first-run wizard or login, embedding, data source, questions, dashboard. Idempotent, so a new add-on is ready in one restart.
